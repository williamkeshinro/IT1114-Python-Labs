# IT1114 - Python Coursework

This repository contains lab assignments completed for IT1114, showcasing progressive Python programming concepts from basic math and conditionals to user-defined functions and nested loops.

## Lab 1: Flooring Cost Calculator
* **File:** `Lab1.py`
* **Description:** Calculates room area, flooring costs, sales tax, and total due based on user inputs.
* **Key Concepts:** Variables, `input()`, `float()`, arithmetic operations.

## Lab 2: KSU Parking Fee Calculator
* **File:** `Lab2.py`
* **Description:** Determines hourly rates and calculates total parking charges based on minutes parked.
* **Key Concepts:** Conditional logic (`if`, `elif`, `else`), decision-making structures.

## Lab 3: KSU CCSE Hackathon Food Cost Calculator
* **File:** `Lab3.py`
* **Description:** Calculates whole pizzas needed, base food costs, bulk discounts, delivery fees, and total amount due.
* **Key Concepts:** Module importing (`math.ceil`), conditional logic (`if`/`else`), multi-step arithmetic modeling.

## Lab 4: Bank Balance & Interest Accumulation
* **File:** `Lab4.py`
* **Description:** Calculates monthly interest earned and updated compound balance over a user-defined timeframe and displays the results in a formatted table.
* **Key Concepts:** Repetition structures (`for` loop with `range()`), compound interest accumulation, string formatting (`\t` tabs and `:.2f`).

## Lab 5: Department Sales & Manager Bonus Calculator
* **File:** `Lab5.py`[cite: 7]
* **Description:** Allows a manager to record weekly sales for an unspecified number of salespeople, tracks department totals against a monthly goal, and computes tiered manager bonuses[cite: 6].
* **Key Concepts:** Nested loops (outer loop for employees, inner loop for weekly sales)[cite: 6], conditional accumulation, and bonus percentages.

## Lab 6: Resort Vacation Cost Calculator
* **File:** `Lab6.py`[cite: 3]
* **Description:** Calculates total resort stay costs including room selection, meal charges with mandatory gratuities, and customizable multiple excursion options[cite: 1, 2].
* **Key Concepts:** User-defined functions (`roomCost`, `mealCost`, `excursionCost`), boolean argument handling, modular program design[cite: 2].

## Lab 7: Prime Number Finder
* **File:** `Lab7.py`[cite: 5]
* **Description:** Prompts the user for a starting and ending number, then identifies and displays all prime numbers inclusively within that range[cite: 4].
* **Key Concepts:** Helper functions (`is_prime`), mathematical divisibility loops, range-based traversal[cite: 4].
